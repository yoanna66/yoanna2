## 01｜揪時間

讓大家更容易約到時間

- **專題介紹**：一個不用註冊，就能邀請朋友一起選擇活動時間的網站。
- **專題成果**：繁體中文介面，手機與電腦都能使用。

**講稿：** 老師好，這次介紹的專題叫做揪時間。它是一個協調活動時間的網站，希望讓大家不用在群組裡反覆詢問，也能找到適合見面的時間。

## 02｜為什麼想做這個網站？

解決大家約時間時常遇到的問題

- **問題一：訊息太多**：大家在群組各自回答，很容易漏看，也不好整理。
- **問題二：時間很難對上**：有人星期一有空，有人星期二有空，很難一次找到交集。
- **適合使用的情境**：朋友聚餐、學生分組討論、社團活動或工作會議。
- **我們的做法**：把候選時間放在同一個頁面，讓大家勾選，再統計結果。

**講稿：** 例如分組討論時，每個人的課表不同。揪時間把候選時段集中起來，讓大家在同一個地方填寫，減少整理訊息的時間。

## 03｜網站怎麼使用？

四個步驟完成時間協調

- **01 建立活動**：輸入活動名稱、發起人暱稱，選擇幾個候選時間。
- **02 分享給朋友**：複製活動連結，或分享 QR Code，讓朋友加入。
- **03 勾選有空時間**：參與者輸入暱稱，選擇可以參加的時段。
- **04 看結果、選時間**：查看各時段的人數，由發起人確認最終時間。

**講稿：** 操作流程很簡單。先建立活動，再把連結傳給朋友。大家不用註冊，填好暱稱和時間後，就可以看到哪些時段最多人能參加。

## 04｜用了哪些工具？

每個工具負責一件事情

- **Next.js、TypeScript**：製作網站頁面、互動功能與處理資料的程式。
- **Tailwind CSS**：設計網站外觀，讓手機和電腦畫面都容易閱讀與操作。
- **Supabase**：作為資料庫，保存活動、候選時間及參與者的答案。
- **開發與上線工具**：ChatGPT／Codex 協助開發；GitHub 保存程式，Vercel 發布網站。

**講稿：** 簡單來說，Next.js 和 TypeScript 負責功能，Tailwind CSS 負責外觀，Supabase 負責保存資料。開發過程使用 AI 協助，程式放在 GitHub，再透過 Vercel 上線。

## 05｜網站和資料庫怎麼連接？

使用者 → 網站程式 → 資料庫 → 顯示結果

- **01 使用者操作**：在手機或電腦開啟網站，填寫並提交答案。
- **02 網站處理**：由 Vercel 上執行的 Next.js 程式檢查並處理資料。
- **03 資料庫保存**：網站程式把答案寫進 Supabase 資料庫。
- **04 顯示統計**：再從資料庫讀取答案，計算各時段能參加的人數。

**講稿：** 使用者按下提交後，不是只把文字留在畫面上，而是由網站程式把答案存到資料庫。因此重新整理後，仍然可以讀取原本的資料。資料庫密鑰只由伺服器使用，不會公開在網頁上。

## 06｜目前完成了什麼？

可以實際操作的專題成果

- **完整協調流程**：能建立不同活動、分享邀請、填寫答案及查看統計。
- **操作更方便**：日期可點選月曆；發起人暱稱自動帶入，返回填寫頁可載入原答案。
- **修改與管理分開**：參與者有私人修改連結；發起人用管理連結確認最終時間。
- **限制與未來改進**：免登入不能完全避免重複填寫；未來可增加通知和截止日期。

**講稿：** 目前已經完成網站並部署上線，包含邀請、填答、統計和修改功能。過程中也依實際使用回饋調整日期選擇與答案保留。仍有可以改善的地方，例如加入提醒或截止時間。
